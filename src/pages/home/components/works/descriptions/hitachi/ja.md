#### 職務内容

Aras Innovator の開発を中心に、ソフトウェア開発やシステム統合に携わりました。

#### 主な業務

- 社内の Aras システムの機能追加・改修（C# / JavaScript）
- 社内の Creo Parametric 用アドオンの拡張・改修（C++）
- 社内の BricsCAD 用アドオンの拡張・改修（VB.NET）
- 必要に応じて WinUI を用いた社内ツールの開発
- 開発した機能のテストおよび検証

#### 詳細

##### Aras

- Aras システム内のフォーム、メソッド（サーバーサイド / クライアントサイド）、変数の追加・更新
- OData を用いて Aras と SAP、Windchill を連携

##### Creo Parametric

- Creo Toolkit を使用して Creo Parametric のアドオンを開発・更新し、主に C / C++ で実装
- 開発したアドオン:
  1. 組立ファイルを CSV にエクスポート（部品一覧）
  2. ファイル名の変更を行い、Windchill 側にも反映

##### BricsCAD

- VB.NET を使用して BricsCAD のアドオンを開発・更新
- 開発したアドオン:
  1. 部品一覧を CSV にエクスポート
  2. 外部のカスタム設定ファイルを読み込む機能

#### 使用技術

- C
- C++
- C#

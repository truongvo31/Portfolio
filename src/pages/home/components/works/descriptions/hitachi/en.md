#### Job description

Worked on software development and system integration projects, with a strong focus on Aras Innovator development.

#### Responsibilities

- Modify and extend the company’s internal Aras system (C# / JavaScript)
- Extend and customize the company’s Creo Parametric add-ons (C++)
- Extend and customize the company’s BricsCAD add-ons (VB.NET)
- Develop internal tools as needed, primarily using WinUI
- Conduct testing and validation for developed features

#### Details

##### Aras

- Add or update forms, methods (server-side or client-side), and variables in the Aras system
- Integrate Aras with SAP and Windchill using OData

##### Creo Parametric

- Create and update Creo Parametric add-ons using the Creo Toolkit, primarily in C or C++
- Developed add-ons:
  1. Export assembly files to CSV (part grid)
  2. Rename files and reflect the changes in Windchill

##### BricsCAD

- Create and update BricsCAD add-ons using VB.NET
- Developed add-ons:
  1. Export part grids to CSV
  2. Read external customized configuration files

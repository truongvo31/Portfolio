#### 職務内容

会社の Web サイトおよび関連する Web 管理業務を担当しました。この役割は、大規模なソフトウェア開発よりも、サイト運営やコンテンツ管理が中心でした。

#### 主な業務

- 会社の Web サイト管理
- 在庫情報（数量、価格、画像、説明文など）の更新
- バナーや宣伝コンテンツの管理
- セールキャンペーンや商品紹介の更新
- 基本的な HTML / CSS / JavaScript を使って簡単なランディングページを設計・開発
- 新機能開発、システム保守、バグ修正のために Web 開発者と連携

#### 使用技術

- HTML / CSS / JavaScript
- Magento e-Commerce
- CS-Cart

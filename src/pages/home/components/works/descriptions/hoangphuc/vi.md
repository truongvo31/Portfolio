#### Mô tả công việc

Quản lý website của công ty và các công việc quản trị liên quan đến web. Vai trò này tập trung chủ yếu vào vận hành website và quản lý nội dung hơn là phát triển phần mềm quy mô lớn.

#### Trách nhiệm chính

- Quản lý website của công ty và danh sách sản phẩm
- Cập nhật thông tin hàng tồn kho, bao gồm số lượng, giá, hình ảnh và mô tả
- Quản lý banner và nội dung khuyến mãi
- Thực hiện các chiến dịch bán hàng và cập nhật cách trình bày sản phẩm
- Thiết kế và phát triển các landing page đơn giản bằng HTML, CSS và JavaScript cơ bản
- Làm việc với nhà phát triển web để triển khai tính năng mới, bảo trì hệ thống và sửa lỗi

#### Công nghệ sử dụng

- HTML / CSS / JavaScript
- Magento e-Commerce
- CS-Cart

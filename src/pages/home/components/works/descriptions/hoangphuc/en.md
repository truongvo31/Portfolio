#### Job description

Managed the company website and related web administration tasks. This role focused mainly on website operations and content management rather than large-scale software development.

#### Responsibilities

- Managed the company website and product listings
- Updated stock information, including quantity, price, images, and descriptions
- Managed banners and promotional content
- Coordinated sales campaigns and product presentation updates
- Designed and developed simple landing pages using basic HTML, CSS, and JavaScript
- Coordinated with web developers for new features, system maintenance, and bug fixes

#### Tech stack used

- HTML / CSS / JavaScript
- Magento e-Commerce
- CS-Cart

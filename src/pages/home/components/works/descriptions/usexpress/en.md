#### Job description

Developed and maintained web applications for the company’s customers.

#### Responsibilities

- Developed customer web applications as a full-stack developer
- Maintained applications that were still within the warranty period
- Conducted testing for newly developed systems

#### Details

- Built both customer-facing and admin-side web applications using ASP.NET Core with MVC for the backend and jQuery/AJAX for the frontend
- Designed and developed application databases using SQL Server, including stored procedures and functions
- Optimized application performance through database-side procedures and SQL queries to avoid issues such as the N+1 query problem
- Improved client responsiveness with an aggressive caching strategy

This was my first real development job, and it taught me many valuable skills.

- How to build a web application using MVC
- How to design a code-first database with Entity Framework
- How to write database procedures and functions
- How to avoid inefficient optimization patterns and reduce server overhead
- What dependency injection is and why it matters
- What caching is and how it improves responsiveness

#### 職務内容

会社の顧客向け Web アプリケーションを開発・保守しました。

#### 主な業務

- フルスタック開発者として顧客向け Web アプリケーションを開発
- 保守期間内のアプリケーションを継続的に保守
- 新規開発したシステムのテストを実施

#### 詳細

- ASP.NET Core を使用し、バックエンドは MVC、フロントエンドは jQuery / AJAX で、顧客向けサイトと管理画面の両方を開発
- SQL Server を使ってアプリケーションのデータベースを設計・開発し、ストアドプロシージャや関数を実装
- N+1 クエリ問題などを避けるため、データベース側の手続きと SQL クエリを最適化
- キャッシュ戦略を活用してクライアントの応答性を向上

#### 学んだこと

これは私の最初の実務開発の仕事で、多くの貴重な経験を学びました。

- MVC を使った Web アプリケーションの開発方法
- Entity Framework を使った Code First データベース設計
- データベースのプロシージャや関数の書き方
- 非効率な最適化やサーバー負荷の増大を避ける方法
- Dependency Injection の概念と重要性
- キャッシュが応答性を向上させる仕組み

#### 使用技術

- C# (ASP.NET Core)
- JavaScript (jQuery)
- SQL Server

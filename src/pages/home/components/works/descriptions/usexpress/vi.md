#### Mô tả công việc

Phát triển và bảo trì các ứng dụng web cho khách hàng của công ty.

#### Trách nhiệm chính

- Phát triển ứng dụng web cho khách hàng với vai trò Full-stack developer
- Bảo trì các ứng dụng vẫn còn trong thời gian bảo hành
- Thực hiện kiểm thử cho các hệ thống mới phát triển

#### Chi tiết

- Xây dựng cả phần giao diện khách hàng và phần quản trị bằng ASP.NET Core, sử dụng MVC cho backend và jQuery/AJAX cho frontend
- Thiết kế và phát triển cơ sở dữ liệu ứng dụng bằng SQL Server, bao gồm stored procedure và function
- Tối ưu hiệu năng ứng dụng thông qua các stored procedure và truy vấn SQL ở database để tránh các vấn đề như N+1 Query Problem
- Tăng tốc độ phản hồi của client bằng chiến lược cache mạnh mẽ

#### Kinh nghiệm đạt được

Đây là công việc phát triển thực sự đầu tiên của tôi, nơi tôi học được rất nhiều kỹ năng có giá trị.

- Cách xây dựng ứng dụng web theo mô hình MVC
- Cách thiết kế cơ sở dữ liệu theo kiểu Code First với Entity Framework
- Cách viết stored procedure và function trong database
- Cách tránh các vấn đề tối ưu hóa kém và giảm tải cho server
- Dependency Injection là gì và vì sao nó quan trọng
- Caching là gì và cách nó giúp cải thiện độ phản hồi

#### Công nghệ sử dụng

- C# (ASP.NET Core)
- JavaScript (jQuery)
- SQL Server
